FINAL TRANSMISSION: HOW IT WAS SEALED

final_transmission.json holds a sealed message. It opens with all four keys and nothing less.

  ikm  = for KEY 01, KEY 02, KEY 03, KEY 04 in that order: 4-byte big-endian length of the UTF-8 key, then the key
  key  = HKDF-SHA256(ikm, salt, info="SPIDEY-TRACXER-FINAL-V1", 32 bytes)
  text = AES-256-GCM decrypt(key, iv, ciphertext). The last 16 bytes of ciphertext are the tag. No additional data.

salt, iv and ciphertext are Base64. A wrong or missing key fails the tag check, with no hint which one was wrong.
Write your own program if you like. The Key Vault decoder opens near the end of the event.
